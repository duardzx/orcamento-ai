# 💰 Orçamento AI - API Rest com Spring AI e OpenAI

Aplicação backend desenvolvida em Spring Boot para gestão e categorização automática de despesas financeiras através do processamento de áudios e inteligência artificial.

## 🚀 Tecnologias Utilizadas
* **Java 17** & **Spring Boot 3**
* **Spring AI** (Integração com OpenAI Whisper e modelos de Chat)
* **Spring Data JPA** & **H2 Database** (Em memória)
* **Dotenv Java** (Gestão segura de credenciais)
* **Lombok**
